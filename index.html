ЗАДАНИЕ 1

Графы и таблица дорог
◈ УСЛОВИЕ

На рисунке схема дорог N-ского района изображена в виде графа, в таблице указаны протяжённости дорог (км).

Нумерация пунктов в таблице не связана с буквенными обозначениями на графе.

Определите сумму протяжённостей дорог E–A и B–C. В ответе запишите целое число.

⌘ РЕШЕНИЕ НА PYTHON
main.pyPYTHON 3
from itertools import *

table = '12 15 16 21 23 32 34 35 43 45 46 51 53 54 61 64'
graph = 'af ae bc bd be cf cb db de df eb ed ea fc fd fa'

for per in permutations('abcdef'):
    new_graph=table
    for i in range(1,7):
        new_graph = new_graph.replace(str(i),per[i-1])
    if set(graph.split()) == set(new_graph.split()):
        print('1 2 3 4 5 6')
        print(*per)
        print()

ЗАДАНИЕ 2

Логическая функция и таблица истинности
◈ УСЛОВИЕ

Миша заполнял таблицу истинности логической функции F:

((x ≡ ¬y) → ¬(w → x)) ∨ ¬z

Он успел заполнить фрагмент из трёх различных строк, не указав соответствие столбцов переменным.

F
0100
000
110

Определите порядок букв w, x, y, z по столбцам таблицы. В ответе укажите четыре буквы подряд.

⌘ РЕШЕНИЕ НА PYTHON
main.pyPYTHON 3
from itertools import *
def f(x,y,w,z):
    return ((x == (not y)) <= (not (w <= x))) or (not z)

for x1,x2,x3,x4,x5 in product([0,1],repeat=5):
    tb=[(x1,0,1,0),(0,x2,x3,0),(x4,1,1,x5)]
    if len(tb)==len(set(tb)):
        for p in permutations('xywz'):
            if [f(**dict(zip(p,row))) for row in tb]==[0,0,0]:
                print(*p,sep='')

ЗАДАНИЕ 10

IP-адрес и маска сети
◈ УСЛОВИЕ

В терминологии сетей TCP/IP маской сети называют двоичное число, которое показывает, какая часть IP-адреса узла относится к адресу сети, а какая — к адресу узла.

Адрес сети получается применением поразрядной конъюнкции к адресу узла и его маске.

Адрес узла: 192.168.159.86
Маска: 255.255.252.0

Найдите адрес сети. В ответе укажите сумму числовых значений октетов найденного IP-адреса.
